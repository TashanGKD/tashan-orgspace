## 聊天与实时

- 私聊要求双方至少共同属于所选组织；群聊只允许当前会话成员访问。
- 消息使用客户端消息 ID 去重，所有发送、编辑、撤回与回应由服务器分配连续事件序列。
- HTTP 是历史真源；WebSocket 订阅先按 cursor 补历史，再通过 Redis hint 拉取缺口，因此重复 hint 不会重复投递。
- WebSocket token 放在子协议，不进入 URL；握手缺少凭证以 4401 关闭，组织成员被移除后以 4403 关闭。
- Web 和 CLI 都支持会话列表、详情、发送、编辑、撤回、回应、附件、@ 提及和消息转任务；CLI 同时支持持续流与 `--once` 历史补发。
- 文件附件要求每一位当前会话成员都有文件权限；消息撤回不删除追加式合规事件。
- 只有组织所有者可以带理由和不超过 31 天的窗口创建聊天合规检查；成功与拒绝均进入审计。

## 搜索与全局工作

- 搜索覆盖组织文件、任务/会议/审批、OKR、Partner、成员和当前可见消息。
- 搜索目录是实时 PostgreSQL view，不复制业务内容；每条候选在返回前再次经过文件、Partner、会话或组织授权。
- 返回数量只统计已授权结果，不暴露隐藏对象总数；撤回消息不进入普通搜索。
- My Work 聚合当前账号在所有有效组织中的任务、审批、会议、提醒和结构化 @ 提及，只保存/返回引用与深链接。
- 成员资格移除后，搜索、My Work 和实时连接都立即失权，没有陈旧缓存继续返回旧内容。
- Partner 待接管管理员视图继续复用 Phase 2D 已验收页面。

## 本轮门禁发现

1. 新增 `chat event stream` 后，CLI 叶子命令门禁拒绝未登记命令；新增独立 `chat.event.stream` capability 后恢复一致。
2. Realtime 首次进入 CLI 单文件分发包时，`ws` 的动态 Node 内置模块加载导致无系统 Node 包启动失败；构建器增加 ESM `createRequire` 桥接，29 项分发测试重新通过。
3. 搜索任务原计划同时写了“复制索引投影”和“不得复制业务状态”；最终采用实时目录视图加领域授权器，以总架构的无副本原则为准。
4. 生产契约门禁新增 Realtime 服务、只读文件系统、JWT/Redis/PostgreSQL 必填项、WebSocket Nginx upstream 和 Docker 源码覆盖的负例自测。
