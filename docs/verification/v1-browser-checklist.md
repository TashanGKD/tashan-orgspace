# OrgSpace v1 浏览器验收清单

## 自动化已通过

- 登录、注册、短信验证码重置密码与旧设备会话撤销。
- 工作区侧边栏、移动导航、组织切换和丢失成员资格边界。
- 组织首页、成员、操作记录、个人/组织文件、任务、会议、审批、OKR、合作方、通知、组织制度、消息、搜索和我的工作。
- 所有业务页面使用列表—详情模型；详情抽屉打开时背景正确进入 `aria-hidden`，键盘焦点留在抽屉。
- Chat composer 的附件 JSON、结构化 @、编辑、撤回、回应和转任务；WebSocket 断线后按 cursor 补历史。
- 生产 Web build 与 Nginx 同源 API/WebSocket 路由。

证据：26 个 Web 测试文件、120 项组件/路由测试；生产形态网关每次组件重启后重复通过 6 项检查。

## 生产登录后手工复验

以下项目必须在 AUP 精确 SHA 部署后执行，当前不标记完成：

- 桌面宽屏：侧边栏展开/折叠、聊天长消息、文件详情、搜索跳转、My Work 跨组织返回。
- 移动窄屏：底部导航、更多模块、详情抽屉、输入法遮挡和长列表滚动。
- 两个真实账号：同组织私聊/群聊实时送达、撤权后连接关闭、通知已读同步。
- 浏览器刷新：HttpOnly refresh cookie 恢复登录，WebSocket 使用新 access token 重连。
